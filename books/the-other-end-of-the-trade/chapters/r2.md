This page collects the formulas the book relies on, grouped by part. Each one links to the numbered display where the book derives it or first works it with numbers, so you can go back to the reasoning when the formula alone is not enough.

Use it as a reminder, not a first introduction. A formula on its own hides its assumptions: the square-root-of-time rule needs independent returns, and Black-Scholes needs a volatility that does not change. The chapter behind each link states what the formula assumes and where it breaks.

## Symbols

The book uses the same symbol for the same thing everywhere, with a few exceptions. A handful of letters, \(G\), \(L\) and \(D\) among them, mean different things in different chapters, so each table below says what they mean there.

| Symbol | Meaning |
|---|---|
| \(S\), \(S_t\) | the price of the underlying, at time \(t\) |
| \(K\) | an option's strike price |
| \(T\) | time to expiry in years; 30 days is \(30/365\) |
| \(R_t\), \(r_t\) | the simple return and the log return over period \(t\) |
| \(r\), \(r_f\) | the risk-free interest rate |
| \(q\) | the dividend yield |
| \(\mu\), \(\sigma\) | the mean return and the volatility, annualized unless a subscript says otherwise |
| \(\sigma_I\), \(\sigma_R\) | implied and realized volatility |
| \(p\) | a probability, often a win rate |
| \(\mathbb{E}[X]\), \(\operatorname{Var}(X)\) | expected value and variance |
| \(N(x)\), \(\varphi(x)\) | the standard normal distribution function and its density |
| \(\Delta\), \(\Gamma\), \(\Theta\), \(\nu\) | delta, gamma, theta and vega |
| \(\rho\) | correlation; the Greek rho is written as a word |
| \(\text{SR}\) | the Sharpe ratio |

The Edge Book's own summary card gives the term-structure filter with other thresholds than its chapter on filters, which Chapter 10H follows. The card halts new short-volatility entries when the ratio stays above 1.05 for 3 days, cuts short volatility by 50% above 1.10 for 3 days, and re-enters in phases once the ratio has been below 1.00 for 5 days. Chapter 10H halts new entries above 1.00, halves the sleeve above 1.05 and keeps only deep tails above 1.15, each after 3 closes. The source does not reconcile the two, and 10H's is the fuller rule.
