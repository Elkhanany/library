# Library UI redesign: plan of record

- `DESIGN.md`: the design system, the navigation model, and the contracts between work packages.
- `plan.json`: the architect's work packages (waves 0 to 5), with acceptance criteria.
- `audit/`: the four lens audits the plan was written from (navigation, reading, front doors,
  phone, dark and accessibility).
- `tools/`: the preview, screenshot, contrast and gate helpers used while building it. They
  hard-code the scratch paths of the session that wrote them, so treat them as reference.

Waves 0 to 4 landed as the commits titled "UI wave N". Wave 5 is the full rebuild and
library-wide review.
